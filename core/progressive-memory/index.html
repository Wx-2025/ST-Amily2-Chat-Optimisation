渐进记忆

按「最近的完整保留、更早的只抽部分」的方式，从指定表格取历史摘要，临时塞进当前对话上下文，让 AI 既记得近事，也能扫一眼更久以前。

内测功能：内容只在本轮对话里临时使用，不写进世界书，也不随聊天导出。

基础设置
按住 Ctrl 可多选；选项值为稳定列 ID。凭证类列默认排除，请仅选择确实需要进入模型上下文的列。
取样设置
表格按时间从旧到新：最新几行完整保留；其余历史对半拆开，较近一半均匀抽若干行、更远一半再均匀抽若干行（固定间距取样，不随机）。
Token 为粗略估算（CJK 约 1/字，其余按 ~4 字符/token）。0 = 不设置更低的用户上限，仍受系统硬上限。
可与「自动隐藏」配合：取样只针对已经滚出视野的旧摘要。注意这里按表格行算，不是聊天消息层——一行总结往往覆盖很多层消息。
什么时候会生效：来源表有效行数低于总结模块的「自动隐藏保留数」时不会塞进上下文——内容太少时近期对话本身就够用。该门槛跟总结模块的自动隐藏设置走，不用单独再配。
远期浓缩摘要（读取宏史卷）
0 = 不设置更低的用户上限，仍受系统硬上限。 不另做压缩：直接读取总结模块史官金账中已经重铸的宏史卷文本，放在记忆块最前面（并标明是早期存档，避免被当成当前剧情）。没用过总结模块或还没生成宏史卷时自动为空，不会额外调用 AI。
如何塞进对话
模板里请包含 {{progressive_memory}}；如果没有，取样内容会直接接在模板后面。
