渐进记忆 (Progressive Memory)

按"近期完整、远期摘要"的时间梯度，从指定表格采样历史并注入上下文——模拟人类记忆衰减，在有限 Token 内兼顾最近连贯与长期回顾。

内测功能：注入内容直达上下文、不写世界书、不随聊天导出，仅当回合生效。

基础设置
采样参数
行序按时间从旧到新：最新 X 行全量；其余历史对半拆，较近一半等距取 Y 行、较远一半等距取 Z 行（中心对齐等距采样，不随机、不首尾加权，避免内容扎堆或事件结局被规律性忽略）。
Token 为粗略估算（CJK 约 1/字，其余按 ~4 字符/token）。0 = 不限制。
与自动隐藏配合：X/Y/Z 梯度只作用于"已隐藏区间"的摘要行。注意单位是表格行而非楼层——一行总结通常覆盖多层楼，请按自己的总结密度设置（如自动隐藏保留 30 层、每行总结约 10 层，则填 3）。
触发门槛：源表有效行数低于总结模块的"自动隐藏阈值"时不注入——源内容太少时近期上下文本就齐全，注入只是冗余。阈值随总结模块自动隐藏设置走，无需单独配置。
注入设置
必须包含占位符 {{progressive_memory}}；缺失时采样内容会追加到模板末尾。
